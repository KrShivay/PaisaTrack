## 2024-05-24 - Set Budget Card Semantic Ripple\n**Learning:** In Flutter, wrapping interactive cards built with `Container` and `GestureDetector` in `Semantics` + `Material` + `InkWell` vastly improves visual feedback (ripples) and clean, single-element announcements for screen readers (via `excludeSemantics: true`).\n**Action:** Use this component pattern (Material > InkWell > Padding) instead of GestureDetector > Container for future interactive custom cards.
