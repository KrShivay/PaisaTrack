## 2024-05-17 - Enhanced interactive widgets with Material + InkWell

**Learning:** Using `Material` and `InkWell` instead of `GestureDetector` wrapped around a `Container` provides built-in material ripples for visual tap feedback and standard accessibility focus states for keyboard navigation.

**Action:** Consistently apply this pattern for custom interactive components like rows and cards to ensure a more accessible and intuitive user experience.
