# T-149 — Local profile

New scope; the handoff's ten screens have no profile. PaisaTrack has no account
(ADR 0002), so "profile" means local personalisation plus a mirror of what the
app knows — never an identity record.

**Hard constraint for all three sub-tasks:** create no identifier that could
correlate across installs. No photo avatars, no account, no stable device id.

### T-149a — Profile shell and personalisation   [P3] [~M]
Files:    `lib/features/profile/profile_screen.dart` (new),
          `lib/features/settings/app_settings.dart`,
          `lib/features/dashboard/dashboard_widgets.dart` (header mascot),
          `lib/features/settings/settings_screen.dart` (entry point)
Depends:  T-152a
Change:   Full-screen sheet reachable from the Home header mascot (currently
          inert) and the top of Settings — **not** a fifth tab; the handoff fixes
          four destinations plus the Ask orb. Holds a display name driving the
          Home greeting ("Hey Shivay") and a mascot accent colour. Both are
          plain settings keys.
Tests:    Widget test: setting a name changes the dashboard greeting; empty name
          falls back to a neutral greeting without showing "Hey ,".
AC:       Reachable from two entry points; no tab count change; no new
          identifier persisted.

### T-149b — Habits and money shape   [P3] [~M]
Files:    `lib/features/profile/profile_screen.dart`
Depends:  T-149a
Change:   Two read-only sections. *Your habits*: streak, transactions sorted,
          average sort time, categories in use, months of history. *Money shape*:
          typical monthly income and spend, top three categories, commitment
          load. Every figure comes from an existing provider — `streakProvider`,
          `dashboard_repository`, `recurring_detector`. Compute nothing new here.
Tests:    Each figure matches the source provider for a fixture dataset. Empty
          history renders zero states, not blanks.
AC:       No number on this screen is derived independently of the surface that
          already owns it.

### T-149c — Data footprint and privacy posture   [P3] [~S]
Files:    `lib/features/profile/profile_screen.dart`
Depends:  T-149a
Change:   *Data footprint*: transactions stored, messages retained, database
          size, model installed and size, last backup. *Privacy posture*:

Tests:    Widget test: figures reflect `model_meta` and settings; the erase link
