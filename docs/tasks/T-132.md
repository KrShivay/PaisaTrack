# T-132 — Lifecycle state split

`transactions.status` holds only a `DecisionStatus` (label confidence). There is
nowhere to record what the bank did, which is why
`GenericTransactionParser._hardReject` discards `failed`, `declined`, `due on`,
and reversal wording. Pending, failed, refunds, reversals, and upcoming bills all
unblock here.
