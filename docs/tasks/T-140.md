# T-140 — Categorization ladder

### T-140a — Merchant memory step   [P2] [~M]
Files:    `lib/enrichment/categorizer.dart:57-95`
Depends:  T-136b, T-143a
Change:   Insert a step between user rules and the classifier: the user's own
          last confirmed label for this merchant, with Laplace-smoothed agreement
          across ≥2 confirmations, at confidence `0.95 × agreement`. This is
          likely the largest single accuracy gain available — the strongest
          predictor of how a user categorizes a merchant is how they categorized
          it last time, and today that signal exists only if it happened to be
          promoted to a rule.
Tests:    Two consistent confirmations produce a high-confidence memory hit;
          conflicting history lowers confidence rather than picking a winner.
AC:       Top-1 accuracy measured before and after against confirmed labels.

### T-140b — Classifier features   [P2] [~M]
Files:    `lib/enrichment/local_classifier.dart:60-84`
Depends:  T-140a
Change:   Raise embedding dimensions 16 → 64. Add merchant transaction count,
          days since last seen for this merchant, amount z-score **within this
          merchant**, and is-round-amount. Replace the ordinal
          `channel.index / n` with a one-hot — an ordinal encoding of an
          unordered enum is actively misleading to a linear model.
Tests:    Feature vector length matches `featureCount`; a stored older model
          still loads or is cleanly rejected as incompatible.
AC:       No crash on a model trained against the old feature count.

### T-140c — Capped LLM category suggestion   [P2] [~S]
Files:    `lib/enrichment/categorizer.dart`
Depends:  T-140b, T-131c
Change:   Add a model-authored category suggestion **capped at 0.70** — below the
          0.90 silent threshold, so it can never auto-apply without a rule, a
          confirmation, or corroboration. This is where the owner's "details may
          be inferred" allowance is spent.
Tests:    A 0.99-confidence model suggestion still cannot auto-apply.
AC:       No LLM suggestion alone changes a category silently.
Rationale: `docs/sms-intelligence-design.md` §8.3.
