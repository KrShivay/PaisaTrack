# T-207 — Intelligence v2 subtasks

Plan: [intelligence-v2.md](../plans/intelligence-v2.md). ADRs 0034/0035 are
Proposed; tasks marked "ADR" may not start until the owner accepts them.
Common rules for every task: read `COLLABORATION.md`, the skills
`intelligence-modules`, `flutter-conventions` (and `db-and-migrations` /
`kotlin-native-bridge` / `sms-template-authoring` where relevant); deterministic
extraction is authoritative, the LLM is advisory (ADR 0011); never log SMS
bodies, VPAs, account/loan/folio/UMRN numbers, amounts or `verbatim`; model
absence must never block capture or any screen. Fixtures are synthetic
(`XBANK`, `XX1234`, round amounts), labelled per ADR 0005. GitNexus `impact`
before editing any existing symbol; `detect_changes --scope all` before commit.
Fact kinds are the closed list in ADR 0034 (`FactKind`).
