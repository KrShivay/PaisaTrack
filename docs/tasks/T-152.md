### T-152a — Add `showBloomFullScreenSheet`   [P2] [~M]

          `showBloomModalSheet`), `lib/core/widgets/bloom/bloom.dart` (export)
Depends:  none
Change:   Full-height draggable route with a 44×5 `#DED8F5` grab handle centred

          threshold, and a mandatory visible exit (back chevron top-left or ✕
          top-right — caller picks, neither may be omitted). Scrim `#1B1830`

          `MediaQuery.disableAnimations` by dropping the drag animation and
          keeping opacity transitions.

          threshold springs back; exit affordance present. Reduce-motion test
          asserts no drag animation. Semantics test asserts the exit control is
          labelled.
AC:       No screen built on this route can be reached without an exit
          affordance. T-145/T-147/T-149/T-151 use it rather than rolling their
          own presentation.
Rationale: handoff README, "Navigation model" — every secondary screen is a
          draggable sheet with an exit.
