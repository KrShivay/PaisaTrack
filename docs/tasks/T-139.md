# T-139 — Subscriptions, EMIs, and price changes

### T-139a — Classify commitment kind   [P2] [~M]
Files:    `lib/intelligence/recurring_detector.dart`
Depends:  T-136b identity, T-138b expected events
Change:   Recurring series are currently undifferentiated. Distinguish **EMI**
          (fixed amount, fixed tenure, `institution` counterparty) from
          **subscription** from **variable bill**. Surface total monthly
          commitment load — a number users rarely compute for themselves.
Tests:    Fixture series of each kind classify correctly; an ambiguous series
          stays unclassified rather than guessing.
AC:       Commitment kind is explainable from evidence shown in the UI.

### T-139b — Price-change insight   [P3] [~S]
Files:    `lib/intelligence/insights_engine.dart`
Depends:  T-139a
Change:   Raise an insight when a series moves beyond the ±5% tolerance the
          detector already tracks via `amountTrend`. Cite both amounts and dates
          ("Spotify ₹119 → ₹149").

          inside tolerance raises none.

          identity fix rather than firing on fragments.
