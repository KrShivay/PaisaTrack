# T-141 — Anomaly precision

### T-141a — Suppress explained deviations and add an amount floor   [P3] [~S]
Files:    `lib/intelligence/anomaly_detector.dart:12-13,70-90`
Depends:  T-139a
Change:   The current rule is 2.5σ over ≥8 baseline periods with no absolute
          floor, so a ₹40 → ₹150 category swing alerts, and an annual insurance
          premium reads as an anomaly every year. (1) Suppress deviations
          explained by a known recurring series. (2) Add an absolute-amount floor
          (default ₹500, via `feature_flags`).
Tests:    An annual premium in a detected series raises no anomaly. A small-rupee
          swing below the floor raises none. A genuine large deviation still does.
AC:       Suppressed anomalies remain inspectable rather than discarded; alert
          volume and dismissal rate are measured.
Rationale: `docs/sms-intelligence-design.md` §10.
