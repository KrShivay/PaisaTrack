# T-199 — Show a local static QR for a transaction VPA

## Request

Show a scannable QR for the stored UPI/VPA on transaction detail and Sort.

## Scope

- Add a shared “Show UPI QR” action in transaction details and on Sort cards
  and list rows for a non-empty, valid stored `counterpartyVpa`. Never infer a
  VPA from a merchant identity, title, or `counterpartyKey`.
- Accept a modest VPA shape with a non-empty local part and handle. Trim
  surrounding whitespace; reject internal whitespace, controls, URI delimiters,
  and malformed values. Do not impose a provider or bank allowlist.
- Encode only a static `upi://pay` URI with `pa` (exact trimmed VPA), `pn`
  (safe bounded transaction title, falling back to the VPA), and `cu=INR`.
  Never include an amount, reference, transaction ID, signed claim, or dynamic
  value.
- Render a black QR on white with a
  four-module quiet zone in a scrollable modal with an explicit close control.
  Show the payee name and exact VPA readably; do not display the URI as
  technical text.
  Keep the code at least 256dp when the available width permits.
- Keep all validation and rendering local. This feature does not launch a
  payment app, resolve a VPA, or verify payee ownership.

## Acceptance

- Unit tests cover exact URI fields, escaping, title fallback, invalid VPAs,
  and absence of amount/reference/transaction identifiers.
- Widget tests cover action visibility, copy behavior, QR display/close,
  dark and light themes, 320dp width and 2× text, with no overflow. Sort action
  tests prove opening/closing the QR does not Keep, Skip, or recategorize a row.
- Export a synthetic rendered QR in `.dart_tool/qa/` for independent decoder
  verification; it contains only the synthetic VPA and title.
- Full Flutter tests, analyze, format, docs/link checks, `git diff --check`, and
  complete GitNexus change analysis pass.
- Physical QA uses only the isolated Recovery QA package and synthetic
  transaction; never inspect owner data or perform a real payment.

## Decision and rollback

See [ADR 0023](../decisions/0023-static-upi-qr.md). Removing the action and
modal restores the prior copy-only VPA presentation.
