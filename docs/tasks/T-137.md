# T-137 — Merchant clustering

Complements T-117 and T-123: converts "paginate thousands of rows" into "resolve
a much smaller set of clusters". Their paging work stays necessary.

### T-137a — Nightly agglomerative pass   [P2] [~M]
Files:    `lib/intelligence/nightly_job.dart`,
          `lib/enrichment/merchant_clusterer.dart` (new)
Depends:  T-136b
Change:   Cluster merchant embeddings at ≥0.85 — deliberately **lower** than the
          online auto-link threshold of 0.92 — and store the result as
          *suggestions*. Never merge automatically. Checkpointed and resumable
          like the rest of the nightly work.
Tests:    Clustering is deterministic for a fixture set; a partial run resumes
          without duplicating suggestions.
AC:       No merchant is merged without user confirmation.
