# T-196 — Transaction details section on the detail screen

## Owner request (2026-10-03)

"I need the UPI, VPA ID or transaction details on the details screen."

## Scope

Add a "Transaction details" card to `TransactionDetailScreen` (Bloom design,
dark/light, 48dp targets, 2.0x text, landscape 964x434) that lists every
stored field that is present, with human labels:

- UPI ID / VPA (`counterparty_vpa`)
- Payee as written in the SMS (`merchant_raw`, when it differs from the title)
- Reference / UPI ref / RRN (`ref_id`)
- Channel (`channel`)
- Account or card (`account_hint` exactly as stored, plus payment-source name)
- Direction, full local date and time
- Balance after (`balance_after`, via `formatSourceAmount`), currency
- Lifecycle state when not settled, parse source

Values are copyable (copy icon or long-press, "Copied" SnackBar) and have
semantics labels. Never invent values or reveal more account digits than
stored. Reuse existing formatters and widgets.

## Acceptance

Widget tests: all fields, minimal fields (only present rows render), copy
action, 2.0x landscape without overflow; full suite, analyze, format,
detect-changes; physical check on the owner phone.

## Privacy and rollback

Shows only data already stored on device. Rollback: remove the card.
