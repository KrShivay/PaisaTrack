# T-189 — Readable Ask prompt list

Status: **In Review**. This task replaces the three clipped horizontal
composer prompts shown after a conversation starts. It does not add a separate
answer-specific follow-up producer. The initial searchable prompt catalogue is
unchanged.

## Scope

In `lib/features/assistant/assistant_screen.dart`, replace the post-conversation
horizontal `ActionChip` row with a vertical list of the same three entries from
`assistantPromptQuestions`. Keep the existing `_askSuggestion` action, manual
rotation control, and `_chipOffset` advance after sending. Each full question
must wrap without line limits or ellipsis, remain individually actionable with
at least a 48dp tap target, and expose a button label to accessibility services.

Keep the list bounded and vertically scrollable so the input composer remains
visible when the sheet is reduced by the keyboard. The empty-state searchable
catalogue and supported assistant intents are out of scope.

## Acceptance

- After a conversation starts, the same three prompts appear as vertically
  stacked full-text rows above the composer.
- Selecting a prompt sends its exact full text and advances to the next three
  catalogue prompts; the rotate control also advances the list.
- At 320dp width with 2× text, long prompt text wraps completely, with no
  `maxLines` or ellipsis, and each row has a minimum 48dp tap target.
- A keyboard-resized sheet with a bottom inset keeps the prompt list scrollable,
  the composer visible, and the screen free of layout overflow.
- The three rotating prompts are not `ActionChip`s; the initial searchable
  catalogue and prompt data stay unchanged.

## Dependencies and privacy

- Dependencies: none. The task is limited to presentation of the existing local
  composer prompt catalogue; T-151b and T-151e answer-bubble work is unrelated.
- Privacy: no transaction-row or SMS text is added to the prompts.
