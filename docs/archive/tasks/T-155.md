# T-155 — Threshold constant consolidation

Confidence thresholds, correlation time windows, and touch-target sizes are
duplicated as inline literals instead of routing through `AppConstants` (or a
new size-token class), so changing one silently drifts from its copies. No
sub-task changes an emitted value — this is reference consolidation only.
