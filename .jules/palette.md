## 2024-09-20 - Custom Navigation Button Semantics
**Learning:** When building custom navigation buttons that combine icons and text wrapped in an `InkWell` or `GestureDetector`, providing a single `Semantics` node at the top level is crucial. The framework's default behavior will read the icon and text separately. Adding `excludeSemantics: true` forces the node to merge the descendants into a clean announcement, but it drops the tap interaction semantics. Therefore, `onTap` and `onTapHint` must be explicitly redefined on the `Semantics` widget itself.
**Action:** Always wrap custom interactive UI elements with a `Semantics` widget. If `excludeSemantics: true` is used, ensure interaction properties like `onTap` and `onTapHint` are manually restored on the `Semantics` node.
